# psyc46050
Homework and other materials for PSYC 46050

## scooby.py

Reads the Mystery Inc. team from `test.yml` and prints each member's role.

```bash
pip install -r requirements.txt
python scooby.py
```

Expected output:

```
Leader: Fred
Fred: leader
Daphne: danger-prone detective
Velma: brains
Shaggy: snack expert
Scooby-Doo: dog
```
